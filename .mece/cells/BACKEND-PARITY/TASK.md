# Backend — Web–Mobile Contract Parity

Own a read-only contract-parity audit between backend/Worker, web, and mobile:
routes, authentication, room/chat models, payload schemas, WebSocket/event
contracts, and error handling. Focus on discrepancies that would affect the
existing room-chat changes or M1 behaviour.

Do not edit files, commit/push, deploy, or run mutating commands. Write only
this cell's `REPORT.md` with evidence-backed findings, severity, file paths,
recommended next actions (not implemented), and the OpenCode session id.
